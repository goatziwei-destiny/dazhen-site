## 優先修正／明確化

### 1. 印章覆蓋正確，但日期末尾辨讀下降（實圖觀察）

sealed-v2 已使用新的正面圓形羊印且壓到日期，方向比 v1 更接近使用者要求。但臉部、衣紋與日期「十一月」重疊，視覺上較混雜。建議保留同一印章和微斜角，降低局部墨濃或將印章右移／上移約 8–15px 作比較，仍需壓到日期，不能退回完全放旁邊。比例約占頁寬 12%，可再比較縮小約 10% 的效果；這是美感建議，不是使用者已要求縮印。

驗收：在整頁縮小觀看時，先讀到「大正」與日期，再看到印章；日期每字仍可辨。不要用大塊白底遮出文字，避免像貼紙。

### 2. 封面標誌規格缺少透視與可視面約束（提示詞風險，未見新成圖）

「完整照形狀與比例」與「斜角封面」需要分開說：平面母圖的星點連線與內部比例不變，貼到封面時整組隨封面透視做同一變形。否則標誌容易像正面貼紙浮在斜書上。

建議補句：『把同一平面標誌映射到封面平面，星點與捲角一起做一致透視；不可只縮扁外圈或單獨移動星點。55% 是封面自身寬度，不是畫布寬度。半開頁只有真正可見的外封面才顯示圖徽，不在內襯複製。』

### 3. 圖徽參考仍帶紙底，容易被帶進綠封面（實圖＋提示風險）

logo-emblem-from-page1.png 是含冷白紙紋的裁切圖，不是可直接貼上的透明標誌。新封面應只取捲角、圓環、星圖與小星輪廓，絕不帶入白色矩形或羊角內的米白填色。先備單色輪廓／透明母版，能降低多角度重畫不一致。

### 4. 半開與翻開各出三版，可能無法成為同一本書（提示詞風險）

目前要求封面三種金＋頁紙三種白，但未明確指定第二階段使用哪一張封面母版。建議先選金色母版，再用同一金色對比三種紙；或明定金 v1 配紙 v1 等配對。每組固定書脊厚度、封面圓角、頁緣厚度、紅書籤錨點與光源。翻開正中央書脊與半開轉軸應能對應；不要只驗單張好看。

### 5. 洋紅背景去背需驗邊，不是生成後就可上線（交付風險）

#FF00FF 工作底可能污染細金線、紙緣與書籤的半透明邊。交付前在深綠、冷白兩種實際背景檢查紫邊、白邊與陰影截斷。若生成工具支援透明，可改用真正 alpha；採洋紅底也可以，但必須有去背後檔案及驗收，不把洋紅底成品當網頁資產。

## PR #30 文字補充審查

這次避免重複句型有進步，但替換後仍可更精確：

- 感情頁「真正卡住的，多半是你在關係裡怎麼付出…」替讀者預設了困境，建議『除了對方是否合適，也可以從付出方式、彼此期待與面對衝突的方法整理關係。』避免為消除一種句型而加入新的斷定。
- 工作頁「財運到底在看什麼：看的是…」有『看』重複，建議『並從賺錢、用錢與守錢的習慣理解財務選擇。』屬編輯選項，不新增服務承諾。
- 「卡很久、還沒打算行動的人」容易讓暫時無力改變的人覺得被排除；若目的是說明不代做決定，可寫『諮詢提供分析與建議，實際選擇與行動仍由您決定。』是否保留原本的強界線由大正決定，不擅改立場。
- PR #30 不僅文案，也含 booking iframe 載入 fallback。新增 bkLoaded 由 iframe load 事件設定，不能因此直接當作內部表單已可互動；請網頁版 GPT 另核 about:blank／錯誤頁／跨網域 load 的失敗狀態。這裡僅為讀碼觀察，未重現故障。
