## 逐項驗收

| 項目 | 通過條件 | 所需證據 |
|---|---|---|
| 完整流程 | 首次正常播放至正文；再次進入依既定記憶策略可讀 | 錄影或逐狀態截圖、測試結果 |
| 狀態連續性 | 同一本書，書脊、書籤、厚度與光源不跳位；封面標誌整組遵循透視 | 固定視窗的 closed/half/open/turn 對照 |
| 翻頁方向 | 右往左；翻過後正文閱讀方向與裝訂一致 | 中間畫格 |
| 圖片載入 | 圖未就緒不切到空白；失敗或逾時可直接讀正文 | 慢載、單圖失敗測試 |
| 略過與連點 | 動畫每個階段可略過；清掉延後事件；連點不啟動多條時間軸 | 自動或人工操作紀錄 |
| 減少動態 | 不只關 CSS，仍可看到完整內容；不因 opacity:0 遺失扉頁 | reduced-motion 渲染 |
| 鍵盤 | 正常觸發、略過；動畫未結束不誤入螢幕外內容；結束焦點移往正文 | 焦點順序紀錄 |
| 手機 | 320、390px 寬及橫向皆可讀；無水平溢出、裁字或隱藏略過 | 尺寸檢查與截圖；實機未測須標示 |
| 去背 | 冷白、深綠底皆無明顯紫邊、殘紙色、黑框 | 兩底對照圖 |
| 文字及印章 | 假名字含長字串不溢出；日期逐字可辨；字不被印章淹沒 | 內頁近看與手機截圖 |
| 內容完整 | 長問題能展開；列印完整；正文可選取，非整頁圖片文字 | 長短假資料、列印檢視 |
