## 4. 美感與點擊流程（請 GPT 一起想，沒有要一次全做）

目前的基調：深藍＋米白＋霧藍＋暖橘、霞鶩文楷字型、星曜羊角色，整體穩重溫和，不需要大改。可以加強的地方：

1. **一個只有大正有的圖形**：用「十二宮格」當網站的記號，例如首頁主視覺旁放一張簡化的命盤格、區塊之間用細的宮格線分隔。比通用的星星、月亮更像紫微斗數。
2. **圖示統一**：有些地方用 emoji、有些用圖片，建議換成同一套線條圖示（同粗細、同圓角），顏色只用深藍和暖橘兩種。
3. **手機底部固定的預約鈕**：捲到一半也能一鍵預約，旁邊寫「最早可約 10/30」，讓客人知道不用等很久。
4. **預約表單的進度**：表單上方顯示「1 命盤 → 2 聯絡 → 3 時段 → 送出」，現在只看得到目前這一步。
5. **好評**：好評頁目前隱藏；等有 3～5 則願意公開的回饋，放 2 則在預約按鈕附近，是最直接的信任感。
6. **文章頁**：長文加「本文目錄」與閱讀進度條；段落維持大正的寫作規範（一個意思寫完才分段）。
