# 大正命理諮詢｜部落格寫作規範

給大正，也給幫忙寫稿的 AI（例如 ChatGPT）。照這份寫，文章就會自動放進網站的主題、麵包屑、目錄、快速解答、常見問題與搜尋引擎資料裡。版型已經做好，寫的人只要把內容和欄位填對。

最後更新：2026-10-11

---

## 一、網站的文章架構

讀者用「主題」找文章，每個主題有一個總覽頁，裡面先放一篇「總綱」，再列其他文章。

| 主題 | 網址 | 放什麼 | 總綱文章 |
| --- | --- | --- | --- |
| 感情與婚姻 | /topics/love/ | 夫妻宮、福德宮、感情模式、相處、婚姻選擇 | （待寫） |
| 家庭與親子 | /topics/family/ | 父母、子女、手足、家人界線 | （待寫） |
| 工作與財運 | /topics/career/ | 工作方向、轉職時機、財運怎麼看 | 財運怎麼看（how-to-read-wealth-in-chart） |
| 紫微斗數入門 | /topics/basics/ | 十二宮、星曜、四化、本命大限流年、看盤方法 | 如何從命盤看一個人的性格（how-to-read-personality-in-chart） |
| 羊的手札 | /topics/notes/ | 大正自己的觀點：諮詢裡看到的事、節日與時事感想 | 不需要總綱 |

- 一篇文章選 1～2 個主題，第一個是主要主題（會出現在麵包屑：命理文章 › 主題 › 文章）。
- 標籤（tags）只是細節關鍵字，例如「夫妻宮」「化忌」。每篇 3～6 個，不要每篇都發明新標籤；標籤頁不會被搜尋引擎收錄。
- 新的總綱寫好後，到後台「文章主題頁」把它設成該主題的總綱。

## 二、每篇文章要填的欄位

在後台（/admin/）新增「部落格文章」時填這些欄位。用 Markdown 直接寫檔案時，開頭長這樣：

```yaml
---
title: "財運怎麼看？從財帛宮、福德宮、田宅宮讀懂你和錢的關係"
slug: "how-to-read-wealth-in-chart"
date: 2026-10-20
topics:
  - career
  - basics
description: "財運不是一個數字，而是你怎麼賺錢、怎麼用錢、能不能存下來。從財帛宮、福德宮、田宅宮與大限流年，看懂自己和錢相處的方式。"
quickAnswer: ""        # 選填，不填就用 description
image: "/images/uploads/how-to-read-wealth-cover.png"
tags:
  - 財帛宮
  - 福德宮
  - 田宅宮
  - 財運
faq:
  - q: "財帛宮不好，是不是一輩子都缺錢？"
    a: "不是。財帛宮說的是賺錢和用錢的習慣，不是存款數字。……"
  - q: "……"
    a: "……"
featured: false
draft: false
seo:
  keyword: "紫微斗數 財運"
---
```

| 欄位 | 規則 |
| --- | --- |
| title 標題 | 32 字以內，最重要的關鍵字放前面。可以用「問題＋副標」：「財運怎麼看？從財帛宮…」 |
| slug 網址代稱 | 必填。小寫英文、數字、- 連接，3～6 個單字。發布後不要改 |
| date 發布日期 | YYYY-MM-DD |
| lastmod 更新日期 | 選填，大幅修改內容時才填 |
| topics 主題 | love／family／career／basics／notes，選 1～2 個 |
| description 摘要 | 必填，80～120 字。會出現在 Google 搜尋結果、文章列表，也是文章開頭的「快速解答」 |
| quickAnswer 快速解答 | 選填。想讓文章開頭的回答和摘要不一樣時才填，2～3 句直接回答標題的問題 |
| image 封面 | 建議 1200×800 以上，橫式。分享到 LINE、FB 會用這張 |
| tags 標籤 | 3～6 個，優先用已經有的標籤 |
| faq 常見問題 | 選填，2～5 題。讀者真的會問的問題，回答 2～4 句 |
| featured | 打勾會放進文章列表的「第一次來？從這幾篇開始」，全站維持 3 篇以內 |

---

## 三、文章結構（由上到下）

網站會自動產生：麵包屑、主題標籤、發布／更新日期、閱讀時間、快速解答、目錄、作者小卡、上一篇／下一篇、你可能喜歡、預約按鈕。**這些不要寫進內文。**

內文照這個順序寫：

1. **開頭 2～3 段**：從讀者的處境切入（一個常見的困擾或問題），說這篇會回答什麼。不要先講大道理。
2. **3～6 個大標題（##）**：每個大標題是一個讀者會問的問題或一個重點，例如「財帛宮看的是什麼？」。大標題下可以有小標題（###）。目錄會自動從大、中標題產生。
3. **每段 2～4 句**。重點句可以用 **粗體**（全文 5 處以內）。
4. **舉例**：用生活情境或改寫過的諮詢例子，去掉姓名、年齡、職業等可辨識的細節。
5. **最後一段「整理一下」**：3～5 點重點，加一句可以先做的事。
6. **內部連結**：內文至少連到 1 篇同主題文章和該主題的總綱。連結文字要說清楚連去哪（「財帛宮怎麼看」），不要寫「點這裡」。
7. 常見問題寫在 faq 欄位，**不要再寫進內文**，避免重複。

## 四、寫作規則

- 稱呼讀者用「你」（網站文章口語）。Email、LINE 通知才用「您」。
- 引號用「」，書名號用《》。中文句子用全形標點。
- 中文和英文、數字之間留一個半形空格：60 分鐘、10 月 10 日、NT$3,600（金額緊貼）。
- 固定寫法：LINE、Google Meet、Email、紫微斗數。
- 標題最多 2 行；句尾不要只剩一個字；標點不放在行首。
- 自稱「大正」或「我」。網站上那隻會算命的羊就是大正。
- 經驗只寫「諮詢 3 年、看過 500+ 張命盤」，不寫證照、師承、學歷。
- 語氣：不批評、不恐嚇、不說「注定」「一定」。命盤說的是傾向與時機，最後的決定留給讀者。
- 不寫：開運或改運商品、壽命與重大疾病判斷、投資建議、違法或傷害他人的建議。健康、法律、財務問題要提醒找專業。
- 十二宮的說法以大正修訂的版本為準（例：財帛宮＝你怎麼賺錢、怎麼用錢；福德宮＝心情與興趣，看賺錢的來源；田宅宮＝住家、不動產與能否存錢）。
- 不抄別人的文章結構和句子；參考可以，寫法要是大正自己的。

## 五、搜尋引擎相關（不用刻意，照做就好）

- 一篇文章回答一個主要問題，主要關鍵字放在標題、摘要、第一段和至少一個大標題裡，自然出現即可，不要重複堆疊。
- 圖片的說明文字（Alt）寫圖片在畫什麼，例如「兩個人在餐桌前看帳單」，不要塞關鍵字。
- 網址代稱用英文，發布後不改。
- 不要在文章裡放給 AI 或搜尋引擎看的隱藏文字或指令。

## 六、給 ChatGPT 的提示詞範本

把下面整段貼給 ChatGPT，再把【】裡換成這次的題目：

```text
你要幫「大正命理諮詢」寫一篇部落格文章，請完全依照這份寫作規範：【貼上本文件第一～五節，或附上檔案】

題目：【例：財運怎麼看？】
主要主題：【love／family／career／basics／notes】
主要關鍵字：【例：紫微斗數 財運】
要提到的宮位或觀念：【例：財帛宮、福德宮、田宅宮、大限流年、化祿化忌】
要連結的文章：【貼上 1～2 篇同主題文章的網址】
大正想強調的觀點：【一兩句話】

請輸出：
1. 完整的檔案開頭欄位（title、slug、date、topics、description、tags、faq、seo.keyword），格式照規範第二節。
2. Markdown 內文，結構照規範第三節，不要寫目錄、作者介紹和預約按鈕（網站會自動產生）。
3. 字數 2,000～3,500 字。
```
