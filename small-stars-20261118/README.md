# 大正體小星定稿｜交給 Claude

將這個追加包匯入現有命盤 HTML，套用在 15 組小星，共 26 個單字。名單以 minor-stars.json 為準。此包與現有命盤主字型及姓名字型共同使用。

## 套用

1. 將 WOFF2 與 minor-stars.css 放在同一個靜態資產目錄。單檔 HTML 專案可以用 data URI 內嵌該 WOFF2 並匯入等效 CSS。
2. 在既有星曜元件中，確認角色是小星且星名在 minor-stars.json 的 stars 清單，才在直排字列加上 data-taisho-minor="完整星名"，每個漢字節點加上 data-taisho-minor-glyph。若現行版用 JSX，可參考下方結構並保留原元件的字級縮放、顏色、排列及功能。光學調整 CSS 應與現有字型規則整合，必要時修正舊的行內字族、字級覆寫。
3. 命盤寬 1311 px 的校樣，小星 18.7 px，寡宿、天巫、鳳閣、孤辰 20.5 px。用現有的小星縮放比例設定 --taisho-minor-scale。兩者使用現有淺、深色字色，以 currentColor 作 0.18／0.26 px 的輕微加重。請在小星文字外層移除舊試排的銘牌框線、底色與陰影樣式。
4. 四組放大字保持原星曜欄內的行距和對齊。保留現有小星以外的字型、姓名後備、四化彩底、排盤及操作邏輯。其他小星沿用程式現有字族。匯出影像前等待新字型載入。

```html
<div data-taisho-minor="孤辰">
  <span data-taisho-minor-glyph>孤</span>
  <span data-taisho-minor-glyph>辰</span>
</div>
```

## 驗收

- 對照淺色命盤.png、深色命盤.png、四組小星局部.png，確認寡宿、天巫、鳳閣、孤辰有正確放大並清晰直排，三台、八座仍可辨讀。
- 確認小星直接顯示在底紙上，字色來自既有主題。盤內的主星「天」和姓名「巫」依舊使用既有字族。
- 此示範盤出現 14 組，請用另一筆盤檢查白虎。另檢查狹窄版面、各層開啟及圖片匯出。
- OTF 供桌面或印刷軟體使用，網頁優先使用 WOFF2。合併後的兩個字型檔與已確認單字輪廓及字寬逐字相同。
