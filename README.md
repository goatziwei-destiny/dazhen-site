## 字型更新摘要

請以這一版整合包更新核心字型。包內同名 OTF / WOFF2 已換成使用者確認的「巫、虛筆勢校正」版本（內部版本 1.530）。請替換原檔並更新字型快取；若 HTML 內嵌 base64，需重新嵌入新版。請在小星「天巫、天虛」及姓名「巫怡君、巫雅婷」驗證。其餘280字元和全部字寬核對一致，姓名擴充與後備字型照舊。

主星、輔星、煞星、小星都用定稿600字重，各自原本的字級、顏色、字距、行距、位置和排盤功能照原程式。

## 接姓名欄

只在實際顯示**姓名值**的元素加上 `taisho-customer-name`。按 CSS 的逐字順序顯示：命盤定稿 → 姓名擴充 → 源流明體 TC → 系統後備。姓名按原始 Unicode 字串當純文字顯示，沿用既有字重設定以外的版面和缺值行為。

若中央出生資料的預設畫面仍由 `ContentEditor` 的 `data-placeholder` 與 `::before` 顯示，確認正式碼後，把預設顯示拆成一般文字節點與一個姓名 span，使 class 只作用在姓名值。保留編輯器、焦點、輸入、儲存與原本的匯出路徑。必要時在既有截圖匯出流程等待字型載入。

保留原命盤排版、星曜和四化、深淺色、全部按鈕、輸入和排盤計算。中央日期、時間和原有英數字重照舊。排盤資料、既有紀錄與匯出格式照原程式處理。
